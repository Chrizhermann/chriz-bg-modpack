# Chriz BG Modpack v0.2.0-alpha.11

## Ready choices

- **Fade and Evandra catch-up (237/238):** on their first Shadows of Amn
  recruitment, each companion is raised to the highest protagonist XP threshold
  reached (125,000 up to 1,250,000). Never lowers XP, pays once, and cannot be
  farmed by dismissing and rejoining. Install before the companion is first
  created, normally before starting a new game.
- **Reader-level scroll casting (430):** replaces the old fixed-level version.
  Arcane and divine scrolls use the reader's active caster level of that type.
  Other legitimate readers use half their highest active class level, rounded
  down, minimum 1; a dormant dual class does not count. Spell Revisions and other
  installed spell changes are resolved by meaning. Scroll learning and genuine
  fixed protection scrolls keep their normal behavior. Requires Windows EEex.
- **Degrodel (660):** when Degrodel asks for the Helm of Balduran you can hand it
  over as before, or keep it: he then stays and fights with the same servants,
  and the quest closes with a short journal note. No extra difficulty is added.
  EET or BG:EE, with or without SCS; the installer skips with a reason when the
  hand-in cannot be identified safely.

## Experimental, optional and off by default

- **Campaign XP banking (650) and the optional SoA cap (651):** BG1 stops usable
  XP at 161,000 and SoD at 500,000; further earned XP is banked and released when
  a later campaign allows it. 651 adds a 2,950,000 cap in Shadows of Amn.
  Existing XP and levels are kept when the component is adopted.
- A dual with no bank follows vanilla: the retired class uses its current level's
  installed XP threshold and discards progress above it, while a banked dual
  keeps its exact pre-reset usable XP baseline.
- The default character record's Class tab shows **Banked XP** with the usable
  limit and when the bank becomes usable. Other interfaces keep the in-game
  notices and the `CBMBank_Status()` console command.
- If banking cannot start, it logs why and stays off; Imoen's Spellhold XP (620)
  and the 237/238 catch-up then keep their normal behavior.
- The first launches in a real game found startup problems that offline checks
  could not show, in both 430 and 650. They are fixed: both now start in a test
  installation (game 2.7.3.0, EEex 1.2).
- Known limits: not yet played through in game; uninstalling 650 or removing
  EEex does not cash out banked XP. Use it only if you accept these limits.

All alpha.10 components remain available. No unrelated defaults changed.

## Install order

- **237/238** after NPC mods, class/kit changes, SCS NPC customization and EET
  finalization, before the companion is created in a game.
- **430** after every spell and item change. Reinstall 430 if a later mod changes
  those resources; startup refuses a stale scroll policy with a visible message.
- **650/651** after the recruitment options you use (237, 238, 620).
- **660** after any mod that changes Degrodel's dialog or his hand-in.

## Testing status

Automated: the full repository suite passes: 2,880 tests with real WeiDU 249,
installer install/uninstall, native hook and accounting checks (including the
call forms EEex writes on a live 2.7.3.0 game). The built release archive passes
its own 11 checks. Three optional checks that read unbundled local game files
were skipped.

In a game: a combined test installation (474 components with Spell Revisions,
game 2.7.3.0, EEex 1.2) installed 237, 238, 430, 650 and 660 (not 651), and
430's scroll analysis reported no errors on its real Spell Revisions spells. In that
game, banking reports that it initialized and scroll casting verifies its
native carriers. Gameplay acceptance of 237/238, 430, 650/651 and 660 is still
pending; the short checks are in
[recruitment XP](../recruitment-xp.md),
[scroll casting](../scroll-casting.md#short-check-for-later),
[banking](../campaign-xp-banking.md#short-check-for-later) and the
[Degrodel guide](../degrodel-fight.md#testing-status).
