# Chriz BG Modpack v0.2.0-alpha.20

## Added

- **697 (`cbm_watchers_keep_teleporters`) — Watcher's Keep: instant teleporters.**
  Overwrites all 36 Watcher's Keep portal cutscenes (`CUT202A`–`CUT202ZH`,
  `CUT211A`, `CUT246A`) and the `AR3001` mirror-portal script (`ITPORTAL`) from
  clean authored `.BAF` sources so teleporting anywhere in Watcher's Keep is
  instant instead of waiting 5–8 seconds behind cutscene fades. Preserves every
  quest/item/statue gate, autosave, exact destination coordinate and facing,
  `CUT202Z`'s one-time Carston cutscene handoff (`cut207a`), and a crisp
  portal flash + `M52` audio cue (`ICRMPARI` / `ICRMPAR2`), while leaving
  `SCUT*` and `CUT208A` untouched. See the
  [Watcher's Keep Teleporters guide](docs/watchers-keep-teleporters.md).
- **698 (`cbm_area_effects_clear_on_leave`) — Clear lingering room effects when leaving an area or hazard room.**
  Installs `override/M_CZRMFX.lua` (Windows x64 **BG:EE**, **SoD**, **BG2:EE**,
  **EET** with **EEex `v1.2.0` or `v1.3.1`**) so room-pulsed hazard debuffs stop
  the moment you leave their room or area instead of lingering up to 14 seconds:
  Dead Magic (`SPIN646` in `AR3004`, `AR3008`, `BD0063`), Wild Magic (`SPIN645`
  in `AR3005`, `AR3009`, `OH6000`–`OH6200`; `SPIN778` per-area), Vicross's
  anti-wild-magic field (`OHNWILDX` in `OH6400`), and Watcher's Keep Level 2 Ice
  Library Slow Freeze (`SPIN628` / `SPIN628A` when leaving the Ice Library
  doors or `AR3016`), plus custom modded areas pulsing those resrefs. Enemy
  combat spells/rays (`SPIN550B`, `SPIN992B`, `SPIN689D`, `SPIN779`, `SPCL132`,
  `SPWM128`) and Black Pits II `OHBANTIM` are never stripped, and paused
  area transitions refresh the actionbar immediately so spellcasting buttons
  un-grey on frame 0. See the
  [Lingering Room Effects guide](docs/area-effects-clear.md).

## Install order

- Install **697** on **BG2:EE** or **EET** (post-`EET_end`; no EEex needed).
- Install **698** on **BG:EE**, **SoD**, **BG2:EE**, or **EET** after **EEex**
  (post-`EET_end` on EET). Overwrites any prior `override/M_CZRMFX.lua`
  cleanly; if `override/M___EEex.lua` is absent, WeiDU logs a clean inactive
  notice without aborting.
