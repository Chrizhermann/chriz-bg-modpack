# v0.2.0-alpha.8

This release adds independently selectable Evandra preferences, story-based
utility XP, generic unidentified-item artwork, and a legacy UI text adapter.
All components released in alpha.7 remain available.

| Component | Result and collection integration |
|---|---|
| **224** `cbm_evandra_sorcerer` | Evandra becomes a Sorcerer with a starting spellbook resolved against the installed spell rules, including Spell Revisions. Her stored level and XP remain intact for recruitment level-ups. Select after Evandra's core and spell/kit providers, before continuity 199 and EET_end. |
| **225** `cbm_evandra_portrait` | Installs Christopher's approved custom portrait independently of 224. Select after Evandra's core. The approved BMP is included unchanged. |
| **611** `cbm_story_utility_xp` | BG1 utility rewards throughout BG1 and SoD, native BG2 rewards from SoA through ToB. Includes the approved BG1 level-16+ lock correction to 155 XP. Requires EET and EEex; install after EET finalization and reward mods. |
| **630** `cbm_unidentified_appearance` | Unidentified items share artwork by item category, including cursed items. Requires Windows BG2EE/EET and EEex/InfinityLoader; install after item/artwork mods. |
| **640** `cbm_legacy_ui_strings` | Supplies the legacy `t()` text helper from `getUiString` when needed. Install after LeUI or Dragonspear UI and before Bubb's Spell Menu. Keeps an existing working `t()` function. |

CEBG will integrate these options separately. Components 224 and 225 are
independent defaults when Evandra's core is selected. Component 611 is the new
approved utility-XP default; **610** remains its mutually exclusive smooth
protagonist-XP alternative, with its runtime unchanged. Component 630 must be
mutually exclusive with Randomiser 570 and the future cursed-appearance option
once that option has a public component number. Ordinary loot randomization
can remain. Component 640 is needed for the selected legacy LeUI/Dragonspear
providers and does not depend on Hidden Gameplay Options.

## Validation and limits

Focused checks exercise SR/non-SR Evandra spellbooks, preserved recruitment
level-up opportunities, portrait fields and provenance, utility-XP campaign
transitions and table preservation, unidentified-artwork Lua/native stubs, and
legacy UI helper load order. Disposable WeiDU fixtures check installation,
reinstallation, rejection of unsupported inputs and restoration on uninstall.
The packaged installer is checked again after extracting the release ZIP, and
two builds must produce identical archive bytes.

These are automated and synthetic checks. No full collection installation,
native gameplay/UI acceptance pass, running game or save modification was part
of this release preparation. The artwork hooks were audited against BG2EE
2.7.3.0; unsupported executable layouts are rejected by signature checks.

Separate unmerged companion-stat and Baeloth work is not included. No unrelated
companion work was migrated from another repository.
