# Chriz BG Modpack v0.2.0-alpha.10

- **Baeloth:** optional standard Sorcerer spells-known selection, with Spell
  Revisions and non-SR choices. Intended for the planned Challenge Mode, not an
  unconditional default. His daily casts and later player choices are preserved.
- **Red Wizard Edwin:** correct his extra slots to the kit's promised +2 total,
  remove the amulet's bonus and let him take it off. Include the BG1 EET template
  missed by Artisan's conversion. Other selected kits are left alone.

All alpha.8 components remain available. No unrelated defaults changed.

## Install order

- **236** follows Artisan NPC **5102**, before Spell Revisions **60**.
- **235** follows all NPC spellbook writers, including SR **60** when selected.
- Both change recruitment resources, not existing saved companions. Collection
  recipe integration and download pins are delivered separately.

The changes are covered by real WeiDU fixture tests, repeat-application and
uninstall checks. No new live-game playtest or save repair is claimed.
See the [Baeloth guide](../baeloth-spellbook.md) and
[Edwin guide](../edwin-redwizard.md) for scope and compatibility.
