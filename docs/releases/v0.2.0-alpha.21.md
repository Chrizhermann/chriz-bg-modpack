# Chriz BG Modpack v0.2.0-alpha.21  ## Added  - **696 (`cbm_no_combat_quickloot`) — Challenge Mode: Disable Quick Loot in Combat.**   Completely disables **Quick Loot** (`WORLD_QUICKLOOT`) while in combat across   **BG:EE**, **SoD**, **BG2:EE**, **EET**, and **IWD:EE** (`2.7.3.0` target,   compatible with `2.6.6.0`) with **EEex** (`v1.2.0` / `v1.3.1`, Lua 5.1 /   Lua 5.2 / LuaJIT 2.1), so players must loot directly from bodies, ground piles,   or containers during active fights. Automatically closes `WORLD_QUICKLOOT` and   resets `groundItemsButtonToggle` when combat begins, blocks actionbar/sidebar   button toggles (with deferred `InfinityUI++` `messagesRect` layout sync), native   `OnKeyDown` Quick Loot hotkey pushes, and slot/mass-pick/scroll callbacks while   leaving direct ground/container looting (`WORLD_CONTAINER`) intact, and restores   Quick Loot automatically once combat ends if it was open beforehand. Syncs live   with `Baldur.lua` `[Challenge Mode] NoCombatQuickLoot` (default `1`),   `CZCombatQuickLoot.SetEnabled(0|1)`, and `chriz-bg-rebalance` Component `370`   (`CBRCHM`). See the [Combat Quick Loot guide](../combat-quickloot.md).  ## Install order  - Install **696** after **EEex** (on **EET**, after `EET_end` and any UI skin   mod such as LeUI, Dragonspear UI++, or InfinityUI++). Also covered offline by `tests/test_combat_quickloot.py` and   `tests/test_release_new_components.py` across Lua 5.1, Lua 5.2, and LuaJIT 2.1,   real WeiDU `249.00` parse/install/`We Overwrite`/uninstall tests across   `BG:EE`, `BG2:EE`, `EET`, and `IWD:EE`, and deterministic release-archive builds.
