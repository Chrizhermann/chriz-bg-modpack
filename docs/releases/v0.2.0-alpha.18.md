# Chriz BG Modpack v0.2.0-alpha.18

## Added

- **470 (`cbm_scroll_learn_fix`) — Spell Learning: restrict ±15% specialist modifier to specialist mages.**
  Fixes the Enhanced Edition `opcode 147` (`CGameEffectLearnSpell::ApplyEffect`)
  engine bug where non-Trueclass kits suffered the −15% other-school penalty on
  regular scrolls and custom mage specialists (such as Red Wizard) failed to match
  their own school(s). Restricts the +15%/−15% specialist modifier to Mage-class
  characters (`CLASS.IDS` `1, 7, 10, 13, 14, 17`) carrying one or more of the 8
  wizard specialist school bits (`0x0040`–`0x2000`), leaving Bards (**Blade**,
  **Jester**, **Skald**, mod kits), **Wild Mages**, kitted dual-class Mages, and
  non-Mages at `0%`. Supports Windows x64 `2.7.3.0` **BG:EE / SoD**, **BG2:EE**,
  **EET**, and **IWD:EE** with EEex (`v1.2.0` / `v1.3.1`). See the
  [Spell Learning RAW Fix guide](docs/scroll-learn-fix.md).
- **690 (`cbm_fast_traps`) — Fast Traps (integrated from *Chriz Fast Traps* `0.2.0`).**
  While **Find Traps** is active, checks doors, containers, and floor traps every
  **15 AI ticks** (~1 second at normal game speed) instead of every 100 ticks
  (~6.67 seconds) across Windows x64 `2.7.3.0` **BG:EE / SoD**, **BG2:EE**,
  **EET**, and **IWD:EE** with EEex (`v1.2.0` / `v1.3.1`), while keeping Detect
  Illusion, passive secret-door searches, skill thresholds, visibility, and Time
  Stop native. See the [Fast Traps guide](docs/fast-traps.md).

## Install order

- Install **470** and **690** after **EEex** (in EET, in the post-`EET_end` pass).
  Both components work without a `GAME_IS` gate in **BG:EE / SoD**, **BG2:EE**,
  **EET**, and **IWD:EE** and overwrite any earlier `override/M_CZSL.lua` /
  `override/M_CZFT.lua`; if `override/M___EEex.lua` is absent, WeiDU logs a clean
  notice without aborting.
