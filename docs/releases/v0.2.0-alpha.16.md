# Chriz BG Modpack v0.2.0-alpha.16

## Changed

- **Every component now writes its decided result.** Hand-edited values,
  another mod's version of the same file, changed text, and missing or extra
  old pieces no longer stop an install, produce a compatibility warning, or
  make a component skip its work. Components replace their owned data and keep
  unrelated data outside that ownership.
- Missing optional targets and individual resources too damaged to change leave
  out only that target or resource, with a normal installer message. Complete
  English descriptions are supplied for changed resources; other game languages
  retain their current descriptions until translations are available.

## What remains required

- Use every component only with its supported game type and any kit, resource,
  or component it genuinely builds on. For example, **651** and **652** each
  require **650** and remain alternatives to one another.
- Features that use EEex still need EEex. Native Windows features keep their
  executable-signature checks before changing memory.

## What you see

There is no new component or selection. The installer no longer reports a
compatibility problem merely because an earlier mod or a hand edit supplied a
different version of a file. A truly unavailable optional target is reported
on its own; the rest of the component continues.

## Install order

Keep the documented order for components that build on another component or
mod-provided kit/resource. Otherwise, alpha.16 adds no new install order.

## Testing status

On 2026-11-08, a full Chriz Easy BG Recommended install on BG2:EE 2.7.3.0 with
EET installed all 466 of 466 components with no errors. The game started and
loaded a save; scroll casting (**430**) reported healthy, and optional campaign
XP banking (**650**) started and banked an award from 2,049 to 2,549 XP.

Earlier full suites on this branch passed: 257 `unittest` tests and 2,194
`pytest` tests. The full install predates the final, test-covered correction to
199's Fate Spirit script, so that exact correction has not yet been through a
full install.

Not yet tested in play: the changed content.
