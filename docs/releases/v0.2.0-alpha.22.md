# Chriz BG Modpack v0.2.0-alpha.22

## Added

- **`699` (`cbm_unpaused_inventory_always`) — Unpaused inventory: always keep the game unpaused in Inventory:**
  Cancels any active singleplayer pause when opening `CScreenInventory` without showing `"Game Paused"` or playing pause audio, restarts `CInfGame::m_worldTimer` if the world screen stopped it during the transition, suppresses pause requests while Inventory stays open, and leaves the game unpaused on close (switching directly to Record, Spellbook, Map, or Options still pauses natively).
- **`700` (`cbm_unpaused_inventory_combat`) — Unpaused inventory: keep the game unpaused in Inventory during combat only:**
  Mutually exclusive with `699`. Preserves native Inventory pause out of combat, and unpauses / blocks pause in Inventory whenever combat is active (`m_nBattleSongCounter` / combat counter `> 0`, or a living party member seeing `[EVILCUTOFF]`), including auto-unpausing if combat begins while paused in Inventory.

See the [Unpaused Inventory guide](../unpaused-inventory.md).

## Install order

- Install at most one of **`699`** or **`700`** after **EEex** (`v1.2.0` / `v1.3.1`; on **EET**, in the post-`EET_end` pass). Supports Windows x64 **BG:EE**, **SoD**, **BG2:EE**, **EET**, and **IWD:EE** (`2.7.3.0` and `2.6.6.0` fallback where matching). If `override/M___EEex.lua` is absent, WeiDU logs an inactive notice without aborting.
