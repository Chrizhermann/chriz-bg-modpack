# Chriz BG Modpack v0.2.0-alpha.12

## New optional choices

- **Companion stats (230-234):** five independent options that raise base
  ability scores: Rasaad DEX 17/CON 16 (**230**), Dorn CON 16 (**231**), Eldoth
  STR 17/INT 14/WIS 9/CON 16 (**232**), Garrick DEX 17/INT 15 (**233**) and
  Quayle CON 15 (**234**). Each patches every listed recruitment and
  later-campaign variant that exists and names any missing one in an installer
  warning. The chosen scores apply whatever the incoming build; stored HP and
  every other field stay unchanged. See the
  [companion stat guide](../companion-stats.md).

## Fixes

- **Faldorn (196) and Dynaheir (197):** a missing creature variant no longer
  blocks the component. Each variant present is patched, missing ones are named
  in installer warnings, and with none present nothing changes. The class, kit
  and death-variable checks on patched variants are unchanged.
- **Release packaging:** builds use exactly the committed files, so a local
  build and the CI build of a release are byte-identical. Installed content is
  unchanged.

All alpha.11 components remain available. No unrelated defaults or collection
selections changed.

## Install order

- **230-234** after companion content, EET's BG1 import and other stat, class
  and kit changes, before the companion first appears. In a split collection
  install, place them with the companion changes before **199**/EET_end.

## Testing status

Automated: the full repository suite passes: 2,892 tests with real WeiDU 249,
including installer install/uninstall and the offline native checks against
the pinned 2.6.6/2.7.3 game executables and EEex 1.2. Three optional checks
that read unbundled local game files were skipped. New 196/197 tests cover all,
some and no variants present, each with exact uninstall. The built release
archive passes its own 12 checks.

In a game: not yet tested. Recruitment, level-up and save/reload with 230-234,
and 196/197 on an installation with missing variants, are still pending.
