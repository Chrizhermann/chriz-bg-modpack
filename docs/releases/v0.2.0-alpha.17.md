# Chriz BG Modpack v0.2.0-alpha.17

## Added

- **680 — EET: story-consistent campaign boundaries and SoD backtracking fixes.**
  Preserves a unified EET install, continuous playthroughs, and all four new-game
  start points (BG1, SoD, SoA, ToB), while removing cross-campaign backtracking
  exploits (`AR0020 <-> BG4800`, `BD1000 <-> BG0900`, `AR3000 -> SoA` from ToB,
  post-SoD `BD4000` reopening) and cleaning out-of-era worldmap icons at each
  campaign entry or transition.
- **SoD chapter 8–10 backtracking fixes (included in 680).** Keeps Ch. 8–10
  road hubs open past the Coalition Camp defense until entering `BD4000`, guards
  `BDPARTY.BCS` `ff_camp` triggers against abandoned camps, forwards/locks old
  `PlayerChest00` containers, preserves un-triggered Baeloth pit cutscenes in
  `BD1000`, and cleans up stale Ch. 8–9 camp sentries, `BDOTILDA`, `BD2000`
  siege audio/actors, and duplicate `BDJEGG` in defended `BD2100`.
- All boundary, Watcher's Keep, and SoD road rules are configurable via
  `chriz-bg-modpack/data/eet_world_progression.2da` (overridable in
  `override/EET_WORLD_PROGRESSION.2DA`). See the
  [EET world progression guide](docs/eet-world-progression.md).

## Install order

Install **680** in the post-`EET_end` pass after EET finalization and any
worldmap, quest, or SoD overhaul mods.

## Testing status

Covered by standalone WeiDU TPA/TP2 parse-checks, synthetic EET install/uninstall
and We Overwrite mutation tests, policy-override tests, extracted release-archive
acceptance tests, and disposable smoke tests on copies of 2.7.3.0 EET
`WORLDMAP.WMP` and script resources. Live in-game playthrough testing across full
campaign transitions remains pending.
