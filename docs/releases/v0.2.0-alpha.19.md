# Chriz BG Modpack v0.2.0-alpha.19

## Added

- **695 (`cbm_bg1_early_party_xp`) — BG1 Early-Party XP Boost (+70% per extra living member up to 16,000 XP).**
  Encourages recruiting a full party right away in **Baldur's Gate 1** instead
  of solo-farming quests before gathering companions. On party-divided XP routed
  through `CInfGame::AddPartyXP`, scales the party pool by `+70%` per additional
  living companion (`STATE_DEAD` clear): `1.0×` solo (`100%`), `1.7×` duo
  (`85%`), `2.4×` trio (`80%`), `3.1×` four (`77.5%`), `3.8×` five (`76%`), and
  `4.5×` six (`75%` per member), rounded on raw pool XP before integer division
  so small early awards still scale cleanly. Evaluates each living protagonist
  and companion individually against a **16,000 total-XP** ceiling (active XP
  plus retired dual-class XP resolved via `XPLEVEL.2DA` and `CBMBank.old.total`
  when Challenge Mode `650` is active), clipping only bonus XP at `16,000`
  without reducing anyone's vanilla `1/N` base share or altering `BD_JOINXP` /
  single-character XP awards. Scoped strictly to Windows x64 **BG:EE**
  (`2.7.3.0`) and **EET** (`2.7.3.0`, plus `2.6.6.0` fallback) with **EEex**
  (`v1.2.0` / `v1.3.1`); never active in solo play, SoD, SoA, ToB, Black Pits,
  Tutorial, or IWD:EE. See the
  [BG1 Early-Party XP Boost guide](docs/bg1-early-party-xp.md).

## Install order

- Install **695** after **EEex** (in EET, in the post-`EET_end` pass; works
  standalone without Challenge Mode `650`–`652` and alongside it). Overwrites any
  earlier `override/M_CZXPBG.lua` cleanly; if `override/M___EEex.lua` is absent,
  WeiDU logs a clean notice without aborting. Never intended for **IWD:EE** or
  plain **BG2:EE** (`GAME_IS ~bgee eet~`).
